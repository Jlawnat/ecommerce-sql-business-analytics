# Licensing and attribution

## Dataset

This project uses the **Brazilian E-Commerce Public Dataset by Olist**, published on Kaggle and licensed under **CC BY-NC-SA 4.0**. The dataset contains anonymized historical marketplace records from 2016–2018.

- Source and acquisition: [Data source](../DATA_SOURCE.md)
- Dataset page: <https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce>
- The raw dataset is not redistributed by this repository.
- Data-derived reuse must retain attribution, remain non-commercial, and use compatible share-alike terms.

## Project code

No root code-license file is currently present. Public visibility alone does not grant an open-source license. Until the repository owner explicitly selects and adds a code license, the code should be treated as copyright-protected with no general reuse permission.

A release decision should choose a code license deliberately and state how it applies to:

- Python, SQL, TypeScript, tests, and documentation written for this project;
- checked-in data-derived aggregate CSV/JSON and generated visualizations;
- third-party dataset attribution and CC BY-NC-SA obligations.

This overhaul does not make that legal choice on the owner's behalf. The missing code license remains a release blocker for describing the repository as formally open source.
